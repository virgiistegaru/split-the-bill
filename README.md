# Split the Bill

A simple web application that helps a group of friends split a restaurant bill equally.

The user can enter the bill amount, the number of people sharing the bill, and the tip percentage. The application then calculates and displays the tip amount, the total bill including the tip, and the amount each person should pay.

## Features

* Enter the restaurant bill amount
* Enter the number of people sharing the bill
* Enter the desired tip percentage, including 0%
* Calculate the tip amount
* Calculate the total bill including the tip
* Calculate the amount each person should pay
* Validate the entered values
* Simple and easy-to-use interface

## Technologies

* HTML5
* CSS3
* JavaScript

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter the bill amount, number of people, and tip percentage.
5. Click **Calculate** to see the results.

No additional dependencies or installation are required.

## Why I Chose This Approach

I decided to build the application using plain HTML, CSS, and JavaScript because the problem is small enough to solve without a framework or backend.

I made the decisions about the structure, functionality, layout, and visual design of the application myself. I wanted to keep the solution simple, easy to understand, and focused on the requirements.

HTML is used for the structure and form, CSS for the visual design and layout, and JavaScript for the calculations, validation, and updating of the results.

## How I Used AI

I used AI as a supporting tool throughout the development process, mainly as a source of advice and guidance.

The decisions about how the application should work, what features to include, how it should look, and how I wanted to structure the solution were my own. I used AI to discuss different approaches, ask for explanations when I encountered unfamiliar concepts, and get suggestions when I was unsure how to implement something.

I did not use AI to make the project independently. I wrote the code myself, made the final implementation decisions, and checked the suggestions before using them.

## How I Checked That the Result Was Correct

I tested the calculations using different combinations of bill amounts, tip percentages, and numbers of people.

For example:

* Bill: 150
* Tip: 10%
* People: 3
* Tip amount: 15
* Total: 165
* Amount per person: 55

I also tested a 0% tip and invalid input values to make sure the application behaved as expected.

## What I Learned / Found Challenging

I learned more about connecting an HTML form with JavaScript, reading user input, performing calculations, validating values, and updating the page dynamically.

I also learned more about CSS layout and styling, including using Flexbox to arrange form elements and creating interactive states such as the button hover effect.

One challenge was deciding how to structure the application while keeping it simple enough to complete within the expected time.
